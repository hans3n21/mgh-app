# MGH Economy Serie

## Kurzbeschreibung

Die MGH Economy Serie wird so effizient wie moeglich gefertigt. Dafuer werden mehrere Economy-Instrumente parallel gebaut. Der Fertigungsbeginn ist deshalb nicht immer fix, sondern startet, wenn genuegend Instrumente in der Warteschlange sind.

## Preisquelle

Der aktuelle Startpreis der MGH Economy Serie muss aus der App-Preisliste (`/app/prices` bzw. `PriceItem`) kommen. Historische Markdown- oder Mailpreise duerfen nicht als dauerhafte Preisquelle verwendet werden.

Wenn kein passender Preiseintrag vorhanden ist, soll die KI keinen Preis nennen, sondern intern darauf hinweisen, dass ein Preiseintrag bzw. ein Angebot angelegt werden muss.

## Specs

| Bereich | Spezifikation |
|---|---|
| Body | Esche, Mahagoni oder Nussbaum |
| Body-Aufbau | Solid Body, ohne Top, mindestens 3-teilig |
| Hals | Ahornhals mit Ahorngriffbrett |
| Halskonstruktion | Schraubhals |
| Kopfplatte | geschaeftete Kopfplatte |
| Griffbrettmarkierungen | nur Side Dots |
| Hardware | Fixed Bridge |
| Pickups | 1 oder 2 Humbucker |
| Mechaniken | Standard-Mechaniken |
| Finish | Oil Wax |

## Darf die KI sagen

- Economy-Instrumente haben einen Startpreis laut aktueller Preisliste.
- Die Serie ist auf effiziente Fertigung ausgelegt.
- Mehrere Instrumente werden parallel gebaut.
- Der Fertigungsbeginn kann davon abhaengen, wann genug Economy-Instrumente in der Warteschlange sind.

## Nicht sagen

- Kein fester Fertigungsbeginn ohne interne Pruefung.
- Keine Zusage, dass jedes Custom-Feature in der Economy Serie moeglich ist.
- Keine verbindliche Lieferzeit ohne Pruefung.
